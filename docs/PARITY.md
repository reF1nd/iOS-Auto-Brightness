# v6.8 功能对照与当前实现

依据：用户提供的闭源包配置、脚本、界面及本地静态行为分析。只重新实现功能，不分发或复制原二进制、网页资源。功能对应不代表逐指令或逐帧输出相同。

| 功能 | beta.6 行为（含 beta.4 补齐项） |
|---|---|
| 主、后置、距离传感器 | 分别注册。前置缺失、注册失败或读数无效时优先使用有效后置；有效前置优先。距离遮挡释放控制。 |
| 光感读取回退 | 前后输入均不可用时在后台读取 sysfs/IIO 照度；只接受单一候选及有限、非负、合理范围的 lux，拒绝未标定 raw 节点。否则精确匹配前置传感器的诊断记录，校验启动会话与单调时间，最多接受 15 秒内记录。失败释放控制，不用无限期缓存。 |
| 学习来源 | 只在直接前置光感有效时学习真实系统亮度事件；按事件时间匹配直接前置历史，系统融合照度只用于事件校验。检查事件前 2 秒及保存等待期的稳定性，注册重启、时钟变化或历史不足时拒绝；后置或诊断回退不制造偏好点。 |
| 稳定期省电 | 调整过程中 250 毫秒，稳定后 800 毫秒、10 秒后 1600 毫秒、20 秒后 8000 毫秒；低电量中间档不低于 2000 毫秒。光感明显变化、模式/滑块与显示事件唤醒处理，手动/灭屏降至 5 秒。看门狗考虑计划睡眠时间。 |
| 夜间修正 | 本地时间 18:00～06:00 默认曲线乘 0.95，可关闭。已保存的明确偏好点优先，不把用户刚选好的亮度再次乘 0.95；这是为保留持久化偏好而做的改进。 |
| 低电量限亮 | 电量低于 15% 且未充电时，增加面板最大值 70% 上限，可关闭；系统更低的上限始终优先。低于 30% 且未充电不启用阳光增强。 |
| 平滑与趋势 | 五点趋势辅助、响应系数插值、明确连续下降时加快照度滤波、分段三次缓动；输出变暗受相对速度上限约束；保留时间归一化，避免轮询变化改变响应速度。 |
| 局部暗读数 | 前置大幅下降而后置仍明显较亮时保持实际亮度、暂停学习，时间本身不解除保护。前置恢复，或后置持续 2 秒支持变暗（绝对照度接近或相对降幅匹配）后恢复跟随；后置失效 5 秒后退回前置。双侧变暗和后置遮挡仍可正常调光。普通下降每秒最多降低当前输出约 20%，不预支空闲时间；系统/低电量上限优先。位置与环境判断仍是启发式，不宣称覆盖所有姿态。 |
| 回差 | `hyst_low/high` 按当前亮度比例插值，恢复低亮/高亮含义。 |
| 阳光模式 | 强光重复确认后进入；70%～100% 触发阈值区间保持，低于 70% 后按配置延迟退出。温度、电量不安全立即取消增强，不等待退出延迟。仍服从系统动态上限。 |
| v6 配置与 Gamma | 首次安装自动校验迁移，已有 v7 配置优先；WebUI 可手动导入。Gamma 保存为兼容字段，不用于已经取得的系统实际亮度。无效旧配置回到默认值并报告原因，不静默套用异常值。 |
| WebUI | 参数、原始配置、配置导入、默认值、实时状态、实际亮度、滑块原值、轮询间隔、传感器来源、曲线当前点、日志自动刷新及清空当前日志；轮转备份保留。显示运行服务版本。 |
| 日志 | 状态变化与明显目标变化记录时间、前后照度、平滑照度、实际/目标亮度、系统上限、温度、电量及处理间隔，用于定位持续使用中的骤降。 |
| 服务、升级与卸载 | 保留单实例、退出释放、监督恢复、冲突检测、轮转；不恢复旧版修改节点权限、PID 误杀和卸载删除学习数据的行为。 |

保留新版修正：连续基础曲线、目标设备标定、系统临时亮度控制、学习点原子持久化、用户隔离、AOD/唤醒处理。原作者头像、联系方式等不属于需要移植的调光功能。系统亮度条同步明确排除在本轮范围外。

验证执行位置为 GitHub Actions；只有通过实际运行和设备观察的项目才能记入 VALIDATION。sysfs/IIO 在当前目标手机缺少可用照度节点，其发现与解析由测试夹具覆盖，不能标成该手机真机回退成功。


## beta.7 再次对照后的补全

此前“缺口全部补齐”的表述范围过宽。此次增加：配置表单、范围滑块与原始文本实时双向同步；未保存参数及阳光模式曲线预览、坐标网格和离线示例；服务离线配置读取与原生校验保存；独立安装/进程/配置/系统状态诊断和离线卡片清空；无默认 Sensor 对象时唯一前置名称发现；quiet/back/battery 等表面温度名称覆盖及系统严重温控抑制。

保留有意差异：不把 SoC 45°C 当作皮肤过热；不绕过系统上限开启 HBM；不恢复原版无限启动失败重试；多点持久化学习和位置变化保护继续生效。通用设备适配、API 基线和明确降级规则见 [兼容性说明](COMPATIBILITY.md)。亮度条同步未纳入这次补全。

## beta.8 补齐上一轮剩余项

| 剩余项 | 本轮实现 | 有意保留的边界 |
|---|---|---|
| 无框架事件/校准时学习 | 显式开启一次学习窗口后，捕获亮度设置通知，保存稳定的实际亮度 | 不把系统自动修改设置误判为用户；不用旧版固定 Gamma |
| 后置与备用照度学习 | 复用稳定照度历史和核心校验，持久记录按来源隔离 | 不混用前后光感坐标 |
| 指定光感来源 | 完整名称、原属性兼容、明确 sysfs 照度节点、WebUI 与离线命令 | 拒绝歧义名称、原始 ADC 与无效路径 |
| 离线日志清理 | 独立 root 命令清空当前与备份日志 | 不触碰学习数据 |
| 状态诊断与 CPU | PID 身份/启动时间、开机标识、心跳过期分类；桥接与核心 CPU | 不把单个进程 CPU 冒充全部开销 |
| 轮转后的最近日志 | 备份与当前日志按序合并，读取/清理/轮转互斥 | 不承诺 copy/truncate 轮转在每次写入边界零丢失 |
| 临时输出请求被系统清除 | 明确确认主屏 automatic 且临时请求已清空后重试 | 原因不明、温控、应用覆盖、HDR 不回拉 |

用户要求的系统温控保护优先：热状态或系统限亮生效时释放控制和暂停学习，清除限制后经过 10 秒恢复等待。不会照搬绕过系统上限或自行修改背光节点的实现。
