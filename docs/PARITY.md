# v6.8 功能对照与 beta.4 实现

依据：用户提供的闭源包配置、脚本、界面及本地静态行为分析。只重新实现功能，不分发或复制原二进制、网页资源。功能对应不代表逐指令或逐帧输出相同。

| 功能 | beta.4 行为 |
|---|---|
| 主、后置、距离传感器 | 分别注册。前置缺失、注册失败或读数无效时优先使用有效后置；有效前置优先。距离遮挡释放控制。 |
| 光感读取回退 | 前后输入均不可用时在后台读取 sysfs/IIO 照度；只接受单一候选及有限、非负、合理范围的 lux，拒绝未标定 raw 节点。否则精确匹配前置传感器的诊断记录，校验启动会话与单调时间，最多接受 15 秒内记录。失败释放控制，不用无限期缓存。 |
| 学习来源 | 只在直接前置光感有效时学习系统亮度事件；后置或诊断回退不制造偏好点。 |
| 稳定期省电 | 调整过程中 250 毫秒，稳定后 800 毫秒、10 秒后 1600 毫秒、20 秒后 8000 毫秒；低电量中间档不低于 2000 毫秒。光感明显变化、模式/滑块与显示事件唤醒处理，手动/灭屏降至 5 秒。看门狗考虑计划睡眠时间。 |
| 夜间修正 | 本地时间 18:00～06:00 默认曲线乘 0.95，可关闭。已保存的明确偏好点优先，不把用户刚选好的亮度再次乘 0.95；这是为保留持久化偏好而做的改进。 |
| 低电量限亮 | 电量低于 15% 且未充电时，增加面板最大值 70% 上限，可关闭；系统更低的上限始终优先。低于 30% 且未充电不启用阳光增强。 |
| 平滑与趋势 | 五点趋势辅助、响应系数插值、明确连续下降时快速变暗、分段三次缓动；保留时间归一化，避免轮询变化改变响应速度。 |
| 局部暗读数 | 前置大幅下降而后置仍明显较亮时，确认 3 秒，再平缓降低；不启用快速变暗。持久差异最终仍跟随前置，不把后置遮挡或方向差异当成固定亮度上限。不能据此宣称已消除所有姿态或局部遮挡影响。 |
| 回差 | `hyst_low/high` 按当前亮度比例插值，恢复低亮/高亮含义。 |
| 阳光模式 | 强光重复确认后进入；70%～100% 触发阈值区间保持，低于 70% 后按配置延迟退出。温度、电量不安全立即取消增强，不等待退出延迟。仍服从系统动态上限。 |
| v6 配置与 Gamma | 首次安装自动校验迁移，已有 v7 配置优先；WebUI 可手动导入。Gamma 保存为兼容字段，不用于已经取得的系统实际亮度。无效旧配置回到默认值并报告原因，不静默套用异常值。 |
| WebUI | 参数、原始配置、配置导入、默认值、实时状态、实际亮度、滑块原值、轮询间隔、传感器来源、曲线当前点、日志自动刷新及清空当前日志；轮转备份保留。显示运行服务版本。 |
| 日志 | 状态变化与明显目标变化记录时间、前后照度、平滑照度、实际/目标亮度、系统上限、温度、电量及处理间隔，用于定位持续使用中的骤降。 |
| 服务、升级与卸载 | 保留单实例、退出释放、监督恢复、冲突检测、轮转；不恢复旧版修改节点权限、PID 误杀和卸载删除学习数据的行为。 |

保留新版修正：连续基础曲线、目标设备标定、系统临时亮度控制、学习点原子持久化、用户隔离、AOD/唤醒处理。原作者头像、联系方式等不属于需要移植的调光功能。系统亮度条同步明确排除在本轮范围外。

验证执行位置为 GitHub Actions；只有通过实际运行和设备观察的项目才能记入 VALIDATION。sysfs/IIO 在当前目标手机缺少可用照度节点，其发现与解析由测试夹具覆盖，不能标成该手机真机回退成功。
